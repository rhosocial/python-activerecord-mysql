Fix MySQL's silent clause drops: `TRUNCATE ... CONTINUE IDENTITY` / `RESTRICT`, `DROP VIEW ... CASCADE` / `RESTRICT`, `[NOT] DEFERRABLE` and `WAIT` / `NO WAIT` on `START TRANSACTION` / `SET TRANSACTION`, the `[NOT] DEFERRABLE` / `INITIALLY ...` family on foreign keys, and `CHECK` `[NOT] ENFORCED` below MySQL 8.0.16 rendered exactly as if the caller had specified nothing; all of them now raise `UnsupportedFeatureError` naming the requested spelling, except `CHECK` `[NOT] ENFORCED` from 8.0.16, which renders. A column-level `REFERENCES` `[NOT] DEFERRABLE` / `INITIALLY ...` no longer renders through the inherited formatter into SQL the server rejects: `MySQLDDLColumnMixin.format_references_clause` refuses it by name. Fix `MySQLExchangePartitionExpression`'s validation state, where the old `with_validation: bool = True` made 'unspecified' and `WITH VALIDATION` the same state and left `WITHOUT VALIDATION` reachable only as `with_validation=False`: neither parameter now renders the clause, `WITH VALIDATION` is rendered only where MySQL accepts it (5.7+) and refused below, and `WITHOUT VALIDATION` is accepted wherever `EXCHANGE PARTITION` exists (5.6+). Fix identity requests, which the deleted `format_identity_clause` override rendered as a bare `AUTO_INCREMENT` for bare / `ALWAYS` / start / increment requests alike, so an identity request is now refused by name.
