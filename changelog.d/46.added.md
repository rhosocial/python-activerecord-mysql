Added schema-diff support for MySQL backend with `MySQLSchemaDiffer`, including
ordinal position tracking for column ordering changes.

Added MySQL-specific DataType subclasses (e.g. `MySQLIntegerType`,
`MySQLTinyIntType`, `MySQLSmallIntType`, `MySQLBigIntType`, `MySQLVarcharType`)
with string formatting and DDL type support for accurate schema introspection.
