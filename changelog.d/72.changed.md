Changed the partition-introspection surface to core's single probe: the backend-local `supports_partition_introspection()` spelling was removed, and `supports_partition_metadata_introspection()` — which MySQL answers `True` — is now the only switch for the partition family, including the CLI's `partitions` type. Callers of the removed name should ask the metadata probe and read partitions through `get_partition_state()`.
